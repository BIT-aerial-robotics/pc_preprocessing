# pc_preprocessing

**This repository contains point cloud preprocessing code and utilities for the paper:**

## Real-Time Multi-Modal Active Vision for Object Detection on UAVs Equipped With Limited Field of View LiDAR and Camera  
🔗 [IEEE Xplore](https://ieeexplore.ieee.org/abstract/document/10233103)

---

## Overview

This repository provides preprocessing tools for multi-modal sensor data — specifically LiDAR and camera — used in real-time object detection from UAVs. It was developed as part of the system proposed in our paper, focusing on efficient handling of limited Field of View (FoV) LiDAR and camera inputs.

Key features include:

- LiDAR point cloud filtering and downsampling  
- Synchronization of LiDAR and camera data  
- Projection and transformation utilities  
- Data preparation for neural network-based object detection
